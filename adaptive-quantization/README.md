# Adaptive Quantization for DAC MCP4725

## Описание
Алгоритм адаптивного квантования для снижения шума квантования.

## Патент
Алгоритм по патенту №2420799 (Бабичев М.М., Пасынков Ю.А.).

## Структура
- `arduino/main.ino` — код для Arduino Uno
- `pc/main.c` — код для ПК (Visual Studio)
-`docs/vkr_adaptive_quantization.pdf` — выпускная квалификационная работа

## Реализация
- Arduino Uno
- ЦАП MCP4725 (I2C)
- Осциллограф DSO138

## Результат
Снижение погрешности первой гармоники в 10–150 раз.
